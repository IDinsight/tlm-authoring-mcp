# Référence

## Qui peut faire quoi

Les rôles sont donnés **par espace de travail** : on peut être curateur dans un espace et sans rôle dans un autre.

| Action | Sans rôle | Curateur | Approbateur | Admin | Super-admin |
|---|:---:|:---:|:---:|:---:|:---:|
| Lire les programmes publiés, les explorer | ✅ | ✅ | ✅ | ✅ | ✅ |
| Modifier le programme et les documents (brouillon) | — | ✅ | ✅ | ✅ | ✅ |
| Appliquer une routine, une mise en forme, une grille | — | ✅ | ✅ | ✅ | ✅ |
| Prévisualiser, produire et déposer des documents | — | ✅ | ✅ | ✅ | ✅ |
| Voir le brouillon dans l'explorateur | — | ✅ | ✅ | ✅ | ✅ |
| Abandonner un brouillon | — | ✅ | ✅ | ✅ | ✅ |
| **Publier** un brouillon | — | — | ✅ | ✅ | ✅ |
| Écrire dans le catalogue et le lexique de l'espace | — | — | ✅ | ✅ | ✅ |
| Consulter l'historique | — | — | ✅ | ✅ | ✅ |
| Supprimer une entrée du catalogue | — | — | — | ✅ | ✅ |
| Gérer les membres, inviter | — | — | — | ✅ | ✅ |
| Créer un espace, l'ouvrir à un domaine, écrire dans la bibliothèque partagée | — | — | — | — | ✅ |

Pour connaître votre rôle : « **Que puis-je faire ?** »

## Trois façons dont une écriture prend effet

Rien ne s'écrit sans votre confirmation. Mais ce qui se passe ensuite dépend de ce que vous modifiez :

| Vous modifiez… | Effet | Filet de sécurité |
|---|---|---|
| **Le programme ou un document** (leçons, sections, images, guide de la matière…) | Va dans le **brouillon** | Rien n'est officiel avant la **publication**. La dernière modification s'annule. |
| **Le catalogue ou le lexique** | **Publié aussitôt** | L'aperçu avant confirmation. Pas d'annulation. |
| **Un fichier livré, un membre** | **Écrit aussitôt** | La confirmation nomme le fichier ou la personne, et l'espace de travail. Pas d'annulation. |

## Petit glossaire

| Terme | Signification |
|---|---|
| **Espace de travail** | Le conteneur d'un programme. Il possède les programmes, le catalogue, le lexique et les documents produits, et c'est lui qui donne les rôles. |
| **Classe / matière** | Le périmètre de travail dans un espace. On travaille sur un seul à la fois. |
| **Graphe de connaissances** | Le programme sous forme de réseau : standards, contenu, documents, et leurs liens. |
| **Standard** | Ce que l'élève doit apprendre. Les niveaux portent les noms que votre programme leur donne. |
| **Objectif** | Un but d'apprentissage précis. C'est ce sur quoi une leçon s'aligne. |
| **Composante d'apprentissage** | Un savoir-faire fin qui détaille un objectif. |
| **Alignement** | Le lien qui dit qu'une leçon **enseigne** (ou qu'une évaluation **évalue**) un objectif. |
| **Cours** | La racine du contenu d'une matière. |
| **Regroupement** | Un ensemble de leçons : chapitre, unité, semaine, jour… selon votre programme. |
| **Leçon** | L'unité d'enseignement, alignée sur un objectif. |
| **Activité** | Ce que fait l'élève : un exercice, avec sa consigne et sa réponse attendue. |
| **Document** | Ce qui est produit : un livre, un guide, une fiche. Il **couvre** une partie du programme. |
| **Section** | Une page ou une partie d'un document, avec ce qu'elle couvre et comment elle s'assemble. |
| **Consigne d'assemblage** | Ce que dit une section sur la façon de composer sa page. |
| **Journal** | La trace datée des décisions prises sur un document ou une section. Ne s'imprime jamais. |
| **Routine pédagogique** | Un déroulé de séance réutilisable. S'applique à un cours, une leçon ou une activité. |
| **Mise en forme** (formatter) | L'apparence d'un document : consignes, réglages de page, gabarits, langues. S'applique à un document. |
| **Gabarit de page** | Une structure de page écrite une fois, que le serveur remplit depuis le programme. |
| **Grille d'évaluation** | Les critères qui jugent un document produit. S'applique à un document. |
| **Catalogue** | La bibliothèque des routines, mises en forme et grilles : une étagère par espace, une partagée. |
| **Lexique** | Les termes de l'espace dans chacune de ses langues ; il guide la traduction. |
| **Guide de la matière** | Les conventions de la matière et ce que le programme doit couvrir, en prose. Claude le lit avant d'écrire. |
| **Brouillon** | Les modifications en attente, pas encore officielles. Un seul par matière. |
| **Publier** | Rendre le brouillon officiel. La production l'utilise alors. |
| **Aperçu** | Un fichier produit à part, pour voir, sans rien livrer. |
| **Livrable** | Un fichier déposé dans l'espace officiel des documents. |
| **Périmé** | Se dit d'un fichier produit avant une modification du programme qu'il couvre. |
| **Module d'autorat** | Le plugin *tlm-autorat* : les procédures que Claude suit, et ses commandes. |
| **Explorateur** | La page web, en lecture seule, qui montre le programme, son brouillon, le catalogue et le lexique. |

## Besoin d'aide ?

- Un problème d'accès ou de compte → l'**administrateur** de votre espace de travail.
- Savoir ce que vous pouvez faire → « Que puis-je faire ? »
- Savoir où vous en êtes → « Où en suis-je ? »
- Connaître les conventions de votre matière → « Lis-moi le guide de cette matière. »
- Ajouter une matière ou un espace → [Administration](admin-developer.md).
